# Weather by Country

Консольное приложение на C#. Читает города из файла, получает текущую погоду через wttr.in и выводит сводку по странам: количество городов, среднюю, минимальную и максимальную температуру.

## Запуск

Нужны .NET SDK 10 и интернет. Открыть терминал в папке с `WeatherByCountry.csproj`:

```powershell
dotnet run
```

Список из задания уже находится в `Cities.txt`. Можно передать другой файл — один город на строку:

```powershell
dotnet run -- "D:\data\Cities.txt"
```

Пустые строки пропускаются, пробелы по краям удаляются, повторы не учитываются независимо от регистра.

Для каждого уникального города выполняется запрос `https://wttr.in/{City}?format=j1`. Температура берётся из `current_condition[0].temp_C`, страна — из `nearest_area[0].country[0].value`. Все значения в сводке вычисляются программой.

Если запрос не удался, программа пишет ошибку и продолжает. Сводка в таком случае помечается как неполная и учитывает только полученные результаты. Ожидание одного ответа ограничено 30 секундами. Отмена — `Ctrl+C`.

## Файлы

- `Program.cs` — чтение файла, удаление повторов, вывод и группировка.
- `WeatherClient.cs` — HTTP-запрос и чтение JSON.
- `WeatherData.cs` — модель города, температуры и страны.

Внешних пакетов нет: используются `HttpClient`, `System.Text.Json` и LINQ из .NET. В репозиторий нужно загрузить исходники, `.csproj`, `Cities.txt`, `.gitignore` и этот README; `bin` и `obj` не нужны.
